Procedural AI video studio

The current implementation requests a generated still image from an external image service, animates it with Canvas camera motion, and records a short WebM video locally. It is a procedural browser workflow, not a direct native Veo-3 rendering API.

How to use this tool

  1. Enter a visual prompt and choose a motion style.
  2. Wait for the still image and Canvas animation.
  3. Preview and download the recorded WebM file.

Frequently asked questions

Does this page call the official Veo-3 model?

No. The repository implementation uses an external image endpoint and local Canvas/MediaRecorder animation.

Is the generated video stored on OMEGA?

The recording is created in the browser, while the source still image is requested from the configured external image service.

Why can generation fail?

The external image service, browser codec support, network, or device memory can cause failure.
