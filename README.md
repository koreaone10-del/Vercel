### ✨ Features
- **100% Client-Side Privacy:** Images are never uploaded to any remote server. Compression happens locally in browser memory.
- **Multilingual Autonomous Detection:** Automatically loads in English, Arabic, Spanish, French, German, Japanese, Chinese, and more based on user locale.
- **Real-Time Telemetry:** Live size metrics (Original Size, Compressed Size, Space Saved %).
- **Interactive UI:** Dynamic cosmos black hole simulation and wireframe 3D head tracker responsive to mouse/touch coordinates.

### 🛠️ Technology Stack
- **Core Engine:** HTML5 Canvas API (Native WebP Encoder)
